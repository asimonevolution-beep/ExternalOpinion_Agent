# External Opinion — REGOLE OPERATIVE

## Regola madre

Minimizzare attrito.
Massimizzare risultato.
Nessuna dispersione.
Nessuna modifica senza sapere quale parte del sistema si sta toccando.

## Gerarchia

1. Centrale Operativa
2. Stato corrente
3. Backup verificati
4. Produzione reale
5. Repo operativo
6. Archivio
7. Memoria AI

## Regole dure

- Se non è chiaro, si ferma.
- Se è produzione, non si tocca senza autorizzazione.
- Se è backup, non si modifica.
- Se è vecchio ma può servire, va in archivio.
- Se è dubbio, va in DA_VERIFICARE.
- Se un agente devia dal task, stop immediato.
- Ogni azione deve avere OK / KO.
